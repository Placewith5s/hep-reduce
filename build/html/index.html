hep_reduce.assert_studio(what: any, err_msg?: string)#

Added in version v2.0.0.

Parameters:

  • what – What to check for assert. Either a condition or a variable

  • err_msg – The error message

Caption:

default error message for conditions: “false!”

Caption:

default error message for other types: “typeof(what) is nil!”

assert_studio Example#
1hep_reduce.assert_studio(game ~= workspace, "DataModel is workspace!") -- nothing happens
hep_reduce.assert_studio_common(
    var: string | number | {any} | Folder,
    err_msg?: string,
    get_descendants?: boolean
)#

Added in version v2.0.0.

Assert studio but for strings, numbers, a certain type of 1D tables, and folders

Parameters:

  • var – The variable to check for assert

  • err_msg – The error message

  • get_descendants – The method used for folders. Defaults to GetChildren()

Caption:

INFO: debug message included for little time saving

Caution:

Does not handle whitespace for strings

assert_studio_common Example#
1hep_reduce.assert_studio_common(folder)
2--[[
3Total folder items: 1
4]]
hep_reduce.award_badge(
    plr: Player,
    badge_id: number,
    logs: {will_own_msg: string, already_owns_msg: string, err_msg: string}
)#

Added in version v2.0.0.

Award a badge to a player

Caption:

Checks if not already owned before awarding

Parameters:

  • plr – The player

  • badge_id – The asset id of the badge

  • logs.will_own_msg – The log message displayed for players who are about to get the badge. Default: “Player will own badge id: badge_id”

  • logs.already_owns_msg – The log message displayed for players who already have the badge. Default: “Player already has badge id: badge_id”

  • logs.err_msg – The error message. Default: “Cannot get badge id: badge_id”

award_badge Example#
1hep_reduce.award_badge(
2        plr, 1234567890,
3        {
4                "Player will own badge name",
5                "Player already owns badge name",
6                "Cannot award badge! Is badge enabled?"
7        }
8)
